### 2.3. Правила семантики цвета (брендбук Phone Agent, п. 5.2)

1. **Синий** (`--primary` / `--accent`) — действия, выбор, активное состояние, линии сервера авторизации на диаграммах.
2. **Зелёный** (`--green`) — только успех и ресурсная сторона (API). Не использовать для акцентов.
3. **Красный** (`--red`) — только опасность: атаки, ошибки протокола, пунктирные стрелки инцидентов.
4. **Янтарный** (`--warn`) — ожидание и предупреждения.
5. Белый текст допустим **только** на `--primary-btn` (`#2b66c4`), не на `--primary` (`#367de3`): 4.04:1 < 4.5:1 — запрещена пара «белый на #367de3».

## 3. Типографика

### 3.1. Шрифты

| Назначение | Шрифт | Фолбэк-стек |

### 3.3. Правила текстов

- **Коротко. Конкретно. Без обвинений** (брендбук 3.3): статусы — факты («Шаг 4 из 20»), инструкции — следующий действие.
- Аббревиатуры RP / AS / API расшифровываются в легенде и в самих названиях узлов: «Приложение (РП)», «Сервер авторизации (АС)».
- Запрещены разговорные формы («ваш бэкенд») и микширование стилей (аббревиатура + разговорное объяснение в одном узле).
- Обрезка текста — только по словам с «…» + тултип `<title>` с полным текстом; hard-clip запрещён.

## 6. Компоненты

### 6.1. Вкладки (tablist)
- Фон зоны: `--muted`; неактивная: прозрачный, текст `--muted-fg`.
- Активная: подчёркивание 2px `--accent` снизу, текст `--fg` (залитый фон активной вкладки запрещён — «синий = выбор, а не заливка»).
- Клавиатура: `role=tablist`, ←/→ переключение.

### 6.2. Кнопки
- Основной («Вперёд»): bg `--primary-btn`, белый текст 12–13px/600, радиус 7px, padding 8px 12px; disabled — opacity 0.4, курсор not-allowed.
- Вторичные/иконки: прозрачный, граница 1px `--border`, hover: bg `--muted`, переход 0.15–0.2s.

### 6.3. Чипы (номера шагов)
- Радиус 5–7px, bg `--muted`, моно-шрифт 11–12px.
- Активный чип: bg `--primary-btn`, текст белый; обычный: текст `--muted-fg`.

### 6.4. Плашки кода / HTTP-трафика
- Бg `--code-bg`, граница 1px `--border`, радиус 7px, Roboto Mono 12–13px, `--muted-fg`/`--fg`.
- Кнопка копирования — иконка, hover `--muted-fg` → `--fg`; после копирования — галочка 2 с.

### 6.5. Диаграмма последовательности (SVG)
- Life-line: 1px `--stroke-strong`, пунктир — только для атак.
- Узлы: rect радиус 7px, bg `--card`, граница `--stroke-strong`; ширина — max(заголовок, подзаголовок), never hard-clip.
- Подписи стрелок: 12px, `--muted-fg`, `paint-order: stroke` с обводкой фона 3px (читаемость поверх линий).
- Цвета сторон: браузер/устройство — `--muted-fg`; приложение (РП) — `--accent`; АС — `--primary`; API — `--green`.
- Стрелки атак: `--red`, пунктир, ⚠-префикс в подписи.
- Тултип: `<title>` на каждом узле/стрелке с полным текстом.

### 6.6. Сайдбар Cheat Sheet
- Ширина 350px, sticky, bg `--card`, граница слева 1px `--border`.
- Аккордеоны — нативные `<details>/<summary>`, chevron 0.2s transform.
- Метрики: моно 11px `--muted-fg`, значения — `--fg`.

## 7. Движение

| Параметр | Значение |
|---|---|
| Hover / фон / цвет | 0.15–0.2s ease |
| Fill SVG (подсветка стрелки) | 0.25s |
| Рисунок стрелок (draw) | последовательная анимация при смене шага |
| Accordion chevron | transform 0.2s |
| `prefers-reduced-motion` | **Уважается**: все анимации отключаются, мгновенные переходы |
| Допустимые свойства | background, color, border-color, fill, opacity, transform — не layout-свойства (без reflow-анимаций) |

## 8. Доступность (обязательный минимум)

| Требование | Статус/значение |
|---|---|
| Контраст текста | `--fg` 13.2:1, `--muted-fg` 6.4:1, кнопки 5.53:1 — всё ≥ 4.5:1 (AA), основной — AAA |
| Focus | 2px solid `--accent`, никогда `outline: none` без замены |
| Клавиатура | Вкладки ←/→, все кнопки/ссылки focusable в порядке DOM |
| Тултипы | Полный текст при любой обрезке |
| reduced-motion | Поддерживается |
| Semantics | `role=tablist/tab/tabpanel`, `aria-label` на иконках, aria-состояния у копирователей |

## 9. Антипаттерны (запрещено)

1. Градиенты, тени, blur, glassmorphism — любой декор поверх плоскости.
2. Фиолетовые/индиго «AI-шрифтовые» акценты — единственный акцент `#83b6ff`/`#367de3`.
3. Белый текст на `--primary` (`#367de3`) — только на `--primary-btn`.
4. Залитый фон активной вкладки — только подчёркивание.
5. Hard-clip текста — только ellipsis + тултип.
6. Отступы вне шкалы 4/8/12/16/24/32, радиусы > 12px.
7. `Math.random()`-подобная случайность в UI, эмодзи в системных статусах (⚠ допустим только как маркер атаки в подписях диаграмм).
8. Замена Inter системным шрифтом; моно-данные (ID, коды, метрики) — только Roboto Mono.
9. Разговорный стиль в интерфейсе; микширование «аббревиатура + просторечное объяснение» в одном элементе.

## 6. ГОТОВЫЕ ОТКРЫТЫЕ РЕШЕНИЯ ДЛЯ ЭКОНОМИИ ТОКЕНОВ (Reverse Engineering)

Вместо разработки с нуля адаптировать уже реализованные проекты (лицензии MIT/Apache 2.0):

| Проект | Лицензия | Что можно скопировать/адаптировать |
|--------|----------|-------------------------------------|
| **Auth0 Dashboard** | Коммерческая (по документации) | Структура пошагового мастера, шаблоны конфигурационных файлов, подсказки к полям |
| **oauthlib** | BSD | Реализация протокола OAuth, валидация redirect URI, scopes |
| **python-social-auth** | MIT | Примеры интеграции OAuth для разных фреймворков |
| **Passport.js** | MIT | Стратегии OAuth для Google, GitHub, VK, примеры кода интеграции |
| **OpenID Connect Discovery** | Apache 2.0 | Стандартная схема обнаружения поставщика (/.well-known/openid-configuration) |
| **PKCE (RFC 8252)** | IETF | Стандарт для публичных клиентов (SPA, мобильные), обязателен в OAuth 2.1 |

**Что конкретно скопировать:**
1. Структура конфигурационных файлов — из Auth0/Okta документации.
2. Валидация redirect URIs и scopes — из oauthlib.
3. Шаблоны кода интеграции — из Passport.js / python-social-auth.
4. Логика пошагового мастера с подсказками — адаптировать из Auth0 Dashboard.
5. Генерация ZIP-архива — стандартные библиотеки (zipfile, JSZip).

**Рекомендуемый следующий шаг:** Изучить OAuth 2.1 (RFC 6749 + RFC 8252) и OpenID Connect Discovery. Адаптировать шаблоны конфигурации из Auth0/Okta под генерацию через веб-интерфейс.

**Ограничение:** использовать только для изучения архитектуры и адаптации; не нарушать права авторов и условия использования поставщиков идентичности.

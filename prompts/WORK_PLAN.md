## 1. ОБЩИЙ ОБЗОР

**Цель проекта:** Создать веб-платформу (онлайн конструктор) OAuth 2.1 / OpenID Connect, где человек без опыта в аутентификации может пошагово, с пояснениями и подсказками, собрать необходимые файлы и выгрузки для интеграции в свой код.

**Конечный продукт:** Веб-приложение с пошаговым мастером, генератором конфигурационных файлов, сниппетов кода, валидатором и экспортом в ZIP-архив.

**Стек (рекомендуемый):**
- Фронтенд: React 18 + TypeScript + Vite + Tailwind CSS
- Бэкенд: Python 3.11 + FastAPI
- Генерация кода: Jinja2 шаблоны
- Валидация OAuth: oauthlib
- Архивация: zipfile (Python) / JSZip (фронтенд)
- Сборка: Docker (опционально)

**Метрика успеха:** Пользователь без опыта в Auth получает готовый архив с файлами и инструкцией за 5–10 минут.

## 3. РИСКИ И МИТИГАЦИИ

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Сложность спецификации OAuth 2.1 / OIDC | Высокая | Высокое | Использовать готовые библиотеки (oauthlib), изучить RFC перед кодом |
| Неверно сгенерированный конфиг не работает у пользователя | Средняя | Высокое | Строгая валидация, тестовые примеры для каждого поставщика, INTEGRATION.md |
| Хранение секретов в репозитории | Низкая | Критическое | .env.example с плейсхолдерами, .gitignore, никаких секретов в коде |
| Пользователь не понимает термины Auth | Высокая | Среднее | Подсказки к каждому полю, простой язык, примеры с картинками |
| Генерация кода для всех стеков затянется | Средняя | Среднее | Начать с React + Python, добавлять остальные стеки итеративно |
